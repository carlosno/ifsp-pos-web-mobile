# Memória Afro-SP — Candomblé em São Paulo

Projeto acadêmico da Atividade Avaliativa 3 — Bootstrap.

## Estrutura

- `index.html` — página única
- `css/style.css` — estilos próprios
- `img/` — ilustrações autorais do carrossel

## Bootstrap

O projeto utiliza Bootstrap 4.6.2, jQuery 3.5.1, Popper e JavaScript do Bootstrap.

## Recursos da aula utilizados

- `container-fluid`
- `navbar navbar-expand-lg navbar-dark bg-dark`
- menu responsivo com `navbar-toggler`
- menu `dropdown`
- `row` e `col-sm-12`
- carrossel com indicadores e controles
- imagens responsivas com `img-fluid`
- CSS próprio para margens, espaçamento e responsividade
- JavaScript para definir o intervalo do carrossel

## Tema

Candomblé, memória e patrimônio cultural afro-brasileiro no estado/cidade de São Paulo,
com destaque para terreiros reconhecidos como referências culturais pela Prefeitura de São Paulo.

## Observação

O conteúdo é educativo e não pretende representar ou revelar práticas internas,
segredos rituais ou informações reservadas de comunidades religiosas.
